# Channel Gate Bot — бот-привратник для закрытого канала

Шаблон №1 из линейки ботов. Автоматически одобряет заявки на вступление
в закрытый канал, отправляет новому участнику приветствие с бонусом
в личные сообщения и даёт администратору панель со статистикой
и массовой рассылкой.

## Кому продавать

Владельцам платных Telegram-каналов, клубов, курсов — всем, кто вручную
одобряет заявки и хочет автоматически прогревать новых участников бонусом.

## Структура проекта

```
bot.py               точка входа
config.py            чтение и валидация .env
states.py            FSM-состояния
database/db.py        работа с SQLite (aiosqlite)
handlers/join_requests.py  одобрение заявок + приветствие
handlers/admin.py     админ-панель, статистика, рассылка
handlers/user.py      ответ обычным пользователям
keyboards/admin_kb.py  инлайн-клавиатуры
```

## Запуск (локально, в PyCharm)

1. Создай виртуальное окружение и установи зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Скопируй `.env.example` в `.env` и заполни:
   - `BOT_TOKEN` — получи у [@BotFather](https://t.me/BotFather)
   - `ADMIN_IDS` — твой Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot))
3. Добавь бота администратором в свой канал с правом
   **«Приглашение пользователей по ссылке»** (Invite Users via Link) —
   без этого бот не сможет одобрять заявки.
4. Запусти:
   ```
   python bot.py
   ```

## Как это тестировать

1. Создай в канале инвайт-ссылку с включённой опцией **«Заявки на вступление»**.
2. Подайте заявку с другого аккаунта — бот должен одобрить её и написать в ЛС.
3. Команда `/start` от твоего (админского) ID должна открыть панель управления.

## Что можно добавить для более дорогой версии

- Проверку оплаты перед одобрением заявки (ЮKassa / Telegram Stars) —
  вступление только после оплаты
- Настраиваемые тексты и кнопки через админ-панель, без правки кода
- Несколько уровней доступа (разные каналы под разные тарифы)
